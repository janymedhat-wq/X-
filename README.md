## Overview

X++ API is a **custom-built graphics and simulation API** designed for interactive simulations, molecular modeling, neural networks, and more. Features include:

- Physics simulations (particles, gravity, collisions)  
- Fluid & gas simulations (2D SPH, water flow)  
- Neural network and scene management
